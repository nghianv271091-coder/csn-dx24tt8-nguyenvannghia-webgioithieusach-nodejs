# HƯỚNG DẪN SETUP VÀ CHẠY CHƯƠNG TRÌNH

## 1. Yêu cầu môi trường

- Máy tính Windows/macOS/Linux.
- Visual Studio Code.
- Trình duyệt Google Chrome, Microsoft Edge hoặc Firefox.
- Extension Live Server trong Visual Studio Code.

## 2. Cài đặt

Bước 1: Clone repository về máy.

Bước 2: Mở thư mục dự án bằng Visual Studio Code.

Bước 3: Cài đặt extension Live Server nếu chưa có.

## 3. Chạy chương trình

Mở file:

scr/index.html

Sau đó nhấn chuột phải vào file index.html và chọn:

Open with Live Server

Trình duyệt sẽ tự động mở ứng dụng.

## 4. Dữ liệu thử nghiệm

Dữ liệu sách được lưu tại:

scr/data/books.json

Dữ liệu bao gồm thông tin về:
- Mã sách
- Tên sách
- Tác giả
- Thể loại
- Năm xuất bản
- Số trang
- Ảnh bìa
- Mô tả

## 5. Kiểm tra chức năng

Sau khi chạy chương trình, kiểm tra:
- Hiển thị danh sách sách.
- Tìm kiếm sách.
- Lọc theo thể loại.
- Sắp xếp sách.
- Xem thông tin chi tiết.
- Chuyển trang.
- Giao diện trên màn hình nhỏ.
