### 1. Công việc đã thực hiện trong tuần
* **Thiết kế dữ liệu:**
  - Xây dựng mô hình dữ liệu tĩnh cho đối tượng sách gồm các thuộc tính: `id`, `title`, `author`, `category`, `year`, `publisher`, `description`, `image`.
  - Tạo file `data/books.json` và `js/data.js` chứa dữ liệu mẫu chuẩn.
* **Xây dựng giao diện cơ bản:**
  - Tạo file `index.html` với cấu trúc semantic: Header, Nav, Search & Filter Bar, Main Content Area (Book Grid), Pagination & Footer.
  - Tạo file `css/style.css` định dạng layout sử dụng CSS Grid cho thẻ sách (Book Cards) và Flexbox cho thanh điều hướng.
* **Lập trình chức năng:**
  - Viết hàm render danh sách sách lên giao diện thông qua DOM manipulation.

### 2. Kết quả đạt được
* Đã hiển thị danh sách sách tĩnh dạng Card trực quan trên trình duyệt.
* Tách biệt rõ ràng phần HTML structure và CSS styling.

### 3. Kế hoạch tuần tiếp theo (Tuần 3)
* Viết chức năng tìm kiếm sách theo tên/tác giả.
* Viết chức năng lọc theo thể loại và sắp xếp.
